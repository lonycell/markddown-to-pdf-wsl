# 마크다운 문서 표지 작성 가이드

## 표지 구성 요소

각 문서의 표지는 다음 요소로 구성됩니다:

1. **YAML Front Matter**: 문서 메타데이터
2. **표지 페이지**: HTML/CSS를 사용한 중앙 정렬 표지
3. **페이지 구분**: 표지와 본문 사이 페이지 나누기

## 표지 템플릿

```markdown
---
title: 문서 제목
author: 작성자/팀명
date: 작성일자
version: 버전
---

<div style="page-break-after: always;"></div>

# 메인 제목
# 부제목

<div style="text-align: center; margin-top: 200px;">

## 문서 제목

**Version 1.0**

**2025년 1월**

---

**작성자/팀명**

</div>

<div style="page-break-after: always;"></div>

# 실제 문서 제목
```

## 사용 예시

### 서비스 기획서
- 제목: 윤이버스 한국어 앱 서비스 기획서
- 작성자: 서비스 기획팀

### 화면 기능 정의서
- 제목: 윤이버스 한국어 앱 화면 기능 정의서
- 작성자: 서비스 기획팀

### 화면 흐름도
- 제목: 윤이버스 한국어 앱 화면 흐름도
- 작성자: 서비스 기획팀

## PDF 변환 시 주의사항

1. **HTML 태그 지원**: Pandoc은 HTML `<div>` 태그를 지원하므로 표지가 제대로 표시됩니다.
2. **페이지 나누기**: `page-break-after: always`를 사용하여 표지와 본문을 분리합니다.
3. **중앙 정렬**: `text-align: center`와 `margin-top`을 사용하여 표지를 중앙에 배치합니다.

## 커스터마이징

표지 스타일을 변경하려면:

1. **여백 조정**: `margin-top` 값을 변경
2. **폰트 크기**: `<h1>`, `<h2>` 태그 사용
3. **구분선**: `---` 사용
4. **추가 정보**: 버전, 날짜, 작성자 등 추가

## 예시: 더 상세한 표지

```markdown
<div style="text-align: center; margin-top: 150px;">

# 윤이버스 한국어 앱
## 서비스 기획서

<div style="margin-top: 100px;">

**Version 1.0**

**작성일**: 2025년 1월

**작성자**: 서비스 기획팀

**문서 분류**: 기획 문서

</div>

---

<div style="margin-top: 50px; font-size: 0.9em; color: #666;">

본 문서는 윤이버스 한국어 앱의 서비스 기획 내용을 담고 있습니다.

</div>

</div>
```
