# 마크다운 & Mermaid → PPT/PDF 변환 가이드

## 방법 1: Pandoc + Mermaid CLI (추천)

### 설치 필요 도구
1. **Pandoc**: 마크다운 → PDF/PPT 변환
2. **Mermaid CLI**: Mermaid 다이어그램 → 이미지 변환
3. **LaTeX** (PDF 변환 시): MiKTeX 또는 TeX Live

### 설치 방법

#### Pandoc 설치
```powershell
# Chocolatey 사용 (관리자 권한 필요)
choco install pandoc

# 또는 직접 다운로드
# https://pandoc.org/installing.html
```

#### Mermaid CLI 설치
```powershell
# Node.js 필요
npm install -g @mermaid-js/mermaid-cli
```

#### LaTeX 설치 (PDF용)
```powershell
# MiKTeX 설치 (Windows)
# https://miktex.org/download
```

### 사용 방법
자동화 스크립트 사용: `convert_to_pdf.ps1` 또는 `convert_to_ppt.py` 실행

---

## 방법 2: Marp (프레젠테이션 전용)

### 설치
```powershell
npm install -g @marp-team/marp-cli
```

### 사용법
```powershell
marp doc/서비스_기획서.md --pdf --theme-set ./themes/
marp doc/서비스_기획서.md --pptx
```

---

## 방법 3: 온라인 도구

### Mermaid 다이어그램
- **Mermaid Live Editor**: https://mermaid.live/
- 다이어그램을 SVG/PNG로 내보내기

### 마크다운 → PDF
- **Markdown to PDF**: https://www.markdowntopdf.com/
- **Dillinger**: https://dillinger.io/

---

## 방법 4: VS Code 확장 프로그램

### 추천 확장
1. **Markdown PDF**: 마크다운을 PDF로 변환
2. **Mermaid Preview**: Mermaid 다이어그램 미리보기 및 내보내기
3. **Markdown Preview Enhanced**: 고급 마크다운 미리보기

### 사용법
1. VS Code에서 마크다운 파일 열기
2. `Ctrl+Shift+P` → "Markdown PDF: Export (pdf)"
3. Mermaid 다이어그램은 자동으로 렌더링됨

---

## 방법 5: Python 스크립트 (자동화)

`convert_to_pdf.py` 또는 `convert_to_ppt.py` 스크립트 사용

### 필요 패키지
```bash
pip install markdown pypandoc python-pptx reportlab
pip install playwright  # Mermaid 렌더링용
playwright install chromium
```
