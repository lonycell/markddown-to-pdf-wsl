# PowerPoint 변환 품질 개선 사항

## 개선된 기능

### 1. HTML 태그 제거
- `<div>`, `<style>` 등 모든 HTML 태그 자동 제거
- HTML 엔티티 디코딩 (`&nbsp;`, `&lt;` 등)
- 깔끔한 텍스트만 슬라이드에 표시

### 2. 스타일링 개선
- **색상 테마 적용**
  - 제목: 진한 파랑 (RGB: 0, 51, 102)
  - 본문: 진한 회색 (RGB: 51, 51, 51)
  - 슬라이드 번호: 밝은 회색 (RGB: 102, 102, 102)

- **폰트 크기 조정**
  - 제목 (레벨 1): 28pt
  - 제목 (레벨 2+): 24pt
  - 본문: 14pt
  - 리스트: 13pt

- **레이아웃 개선**
  - 빈 슬라이드 사용 (더 많은 제어 가능)
  - 여백 조정
  - 텍스트 상자 마진 설정

### 3. 이미지 크기 자동 조정
- **PIL/Pillow 사용** (선택사항)
  - 이미지 비율 유지
  - 슬라이드 크기에 맞게 자동 조정
  - 화면을 벗어나지 않도록 제한

- **레이아웃별 크기 조정**
  - 텍스트 + 이미지: 이미지 4.5인치 너비
  - 이미지만: 이미지 9인치 너비
  - 중앙 정렬

### 4. 마크다운 파싱 개선
- 리스트 항목 자동 감지 및 불릿 포인트 변환
- 빈 줄 및 구분선 무시
- 코드 블록 제외

## 사용 방법

### Python 스크립트 (개선 버전)

```bash
python3 convert_to_ppt.py [출력폴더]
```

### Bash 스크립트

```bash
./convert_to_ppt.sh [출력폴더]
```

## 추가 패키지 (선택사항)

이미지 크기 자동 조정을 위해 Pillow를 설치하면 더 정확한 크기 조정이 가능합니다:

```bash
pip install Pillow
```

설치하지 않아도 기본 크기로 작동합니다.

## 개선 전후 비교

### 개선 전
- HTML 태그가 텍스트로 표시됨
- 단조로운 스타일
- 이미지가 화면을 벗어남
- 레이아웃이 일정하지 않음

### 개선 후
- HTML 태그 완전 제거
- 색상 테마 및 스타일 적용
- 이미지 크기 자동 조정
- 일관된 레이아웃
- 리스트 항목 자동 포맷팅

## 커스터마이징

색상 테마를 변경하려면 `convert_to_ppt.py` 또는 `convert_to_ppt.sh`의 `theme_colors` 딕셔너리를 수정하세요:

```python
theme_colors = {
    'primary': RGBColor(0, 51, 102),      # 제목 색상
    'text': RGBColor(51, 51, 51),         # 본문 색상
    'light_text': RGBColor(102, 102, 102) # 슬라이드 번호 색상
}
```
